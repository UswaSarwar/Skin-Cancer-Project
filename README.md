# 🧠 Skin Cancer Detection using Deep Learning (CNN)

## 📌 Overview

This project is a deep learning-based skin cancer classification system using a Convolutional Neural Network (CNN). It analyzes dermatoscopic images and predicts different types of skin lesions.

This project is built for educational purposes to demonstrate how Artificial Intelligence can assist in early detection of skin cancer.

---

## 🚀 Features

- 🖼️ Image-based skin lesion classification
- 🤖 CNN deep learning model
- 📊 Multi-class classification
- ⚡ Fast prediction system
- 🌐 Flask web interface
- 📈 Model training and evaluation

---

## 🛠️ Tech Stack

- Python 🐍
- TensorFlow / Keras 🤖
- NumPy & Pandas 📊
- OpenCV 📷
- Flask 🌐
- HTML, CSS, JavaScript 💻

---

## 🧠 Classes

- Actinic keratoses (akiec)
- Basal cell carcinoma (bcc)
- Benign keratosis-like lesions (bkl)
- Dermatofibroma (df)
- Melanocytic nevi (nv)
- Melanoma (mel)
- Vascular lesions (vasc)
